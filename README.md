# Учебный проект по верстке лендинга с анимациями

## Stack
HTML,CSS, адаативная верстка

## Описание
Проект "Место" представляет собой одностраничный сервис, где рользователи могут выкладывать фото из разных мест. Другие пользователи могут смотреть фото, открывая их и ставя/убирая лайки. В проекте также реализована  настройка профиля (фото, имя, род деятельности). Фото и профили хранятся на сервере, в подборку могут попасть не работающие фото, так как сервер учебный.
Верстка адаптивная "резиновая" + break point. Еще структура проекта составлена по БЭМ классификации.

[макет](https://www.figma.com/design/iCqhYZoj4CTFvBjQaBSAXq/JavaScript.-Sprint-5--Copy-?node-id=0-1&p=f&t=ZVCP15pfZlVNoL6O-0)

## Stack: 
*HTML
*CSS
* Webpack + Babel
* ESLint + Prettier

## Запуск проекта:
1. Установть все необходимые пакеты `npm i`
2. Запустить проект `npm run dev`
