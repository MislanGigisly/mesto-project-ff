# Mesto Project FF

Проект “Место” — одностраничный сервис, где пользователи могут выкладывать фото из разных мест. Другие пользователи могут просматривать фото, ставить/снимать лайки. Также реализована настройка профиля (имя, род деятельности, аватар). Верстка адаптивная, есть “резиновость” + breakpoint’ы. Структура построена с применением БЭМ-классификации.

## :building_construction: <a id="structure">Структура проекта</a>
| Файл / папка             | Описание                             |
|--------------------------|----------------------------------------|
| `src/`                   | Исходный код проекта                  |
| ├── `blocks/`            | Стили, организованные по БЭМ-блокам   |
| ├── `components/`        | JS-модули для функционала (popup, карточки, валидация форм и т.д.) |
| ├── `images/`            | Изображения проекта                   |
| ├── `pages/`             | Стили для отдельных страниц           |
| ├── `scripts/`           | Точка входа и вспомогательные скрипты |
| ├── `index.css`          | Общие стили                           |
| └── `index.js`           | Главный JS-файл (точка входа)         |
| `webpack.config.js`      | Конфигурация сборки через Webpack     |
| `babel.config.js`        | Настройки транспиляции с помощью Babel |
| `postcss.config.js`      | Настройки PostCSS                     |
| `package.json`           | Скрипты, зависимости проекта          |
| `package-lock.json`      | Фиксированные версии пакетов          |
| `.gitignore`             | Исключения при коммите                |
| `README.md`              | Описание проекта                      |

## 🎯 <a id="features">Особенности реализации</a>

- Верстка адаптивная, “резиновая” + breakpoint’ы  
- БЭМ-классификация CSS  
- Возможность добавления/удаления фотографий  
- Лайки под фото  
- Настройка профиля пользователя (имя, статус, аватар)  
- Интеграция сборщика и инструментов качества (Webpack, Babel, ESLint, Prettier)
